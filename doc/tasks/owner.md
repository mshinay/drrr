# 房主管理模块任务列表

> 来源：`doc/proposal.md` 7 房主机制；`doc/detailed-design.md` 5.6 房主管理模块。

## 目标

交付初始房主设置、房主继承、房主权限判定和成员房主标记维护。

## 前置约定

- 房主继承只在房主实际离房或被清理为离线离房时触发。
- 按成员 `joinedAt` 升序选择最早加入且仍有效的成员。
- 并发继承由单体服务按 `roomId` 粒度串行化处理。

## 最小任务

- [ ] 定义 `OwnerTransferResult` 结构。
- [ ] 定义 `OwnerPermissionCheck` 结构。
- [ ] 封装当前房主读取逻辑，来源为 `drrr:room:{roomId}`。
- [ ] 实现初始房主设置：房间创建者写入 `Room.ownerUserId`。
- [ ] 实现初始房主设置：创建者成员视图标记为 `isOwner=true`。
- [ ] 实现房主权限校验入口。
- [ ] 房主权限校验读取房间主数据并比较 `ownerUserId`。
- [ ] 房主权限校验对房间不存在返回失败。
- [ ] 实现房主离房后的继承入口。
- [ ] 按 `drrr:room:members:{roomId}` 的 `joinedAt` 升序读取候选成员。
- [ ] 过滤已离房成员。
- [ ] 过滤对应用户会话缺失的脏成员。
- [ ] 选择最早加入的有效成员作为新房主。
- [ ] 更新旧房主成员标记为 `isOwner=false`。
- [ ] 更新新房主成员标记为 `isOwner=true`。
- [ ] 更新 `Room.ownerUserId`。
- [ ] 触发 `OWNER_TRANSFER` 房间事件。
- [ ] 通知聊天模块生成房主转移系统消息。
- [ ] 无剩余成员时返回不继承结果，由房间模块继续进入空房逻辑。

## 测试验收

- [ ] 创建房间时创建者自动成为房主。
- [ ] 非房主权限校验失败。
- [ ] 房主离开后按加入顺序继承。
- [ ] 房主离开且无剩余成员时不产生新房主。
- [ ] 成员索引存在脏数据时仍能跳过并选出正确继承人。
- [ ] 房主转移后事件和系统消息调用被触发。

## 完成定义

- [ ] 房主管理模块任务全部完成。
- [ ] 权限校验和继承排序测试通过。
- [ ] 与房间模块的离房流程衔接清晰。
