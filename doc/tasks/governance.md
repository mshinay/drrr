# 禁言/Ban 模块任务列表

> 来源：`doc/proposal.md` 7.2 房主权限、11 禁言与Ban；`doc/detailed-design.md` 5.7 禁言/Ban 模块。

## 目标

交付禁言、踢出、永久 Ban，以及消息发送前和加入房间前的治理校验能力。

## 前置约定

- 禁言自定义时长单位为整数分钟。
- 重复禁言同一用户时以后一次设置覆盖。
- 踢出不等同于 Ban；未被 Ban 的用户可重新加入。

## 最小任务

- [ ] 定义 `MuteRecord` 数据结构。
- [ ] 定义 `BanRecord` 数据结构。
- [ ] 定义 `GovernActionResult` 输出结构。
- [ ] 封装 `drrr:room:mute:{roomId}` 禁言索引读写删除逻辑，score 使用 `endAt`。
- [ ] 封装 `drrr:room:mute:detail:{roomId}:{userId}` 禁言详情读写删除逻辑。
- [ ] 封装 `drrr:room:ban:{roomId}` Ban 集合读写逻辑。
- [ ] 封装 `drrr:room:ban:detail:{roomId}:{userId}` Ban 详情读写逻辑。
- [ ] 实现禁言入口。
- [ ] 禁言前校验操作者是房主。
- [ ] 禁言前校验目标成员存在。
- [ ] 禁言前校验目标不是当前房主。
- [ ] 校验禁言时长合法，计算 `endAt`。
- [ ] 写入禁言索引和禁言详情。
- [ ] 触发 `USER_MUTED` 房间事件。
- [ ] 通知聊天模块生成禁言系统消息。
- [ ] 实现消息发送前禁言校验。
- [ ] 禁言校验命中且未过期时返回禁言中。
- [ ] 禁言校验发现已过期时清理索引和详情，并返回未禁言。
- [ ] 实现踢出入口。
- [ ] 踢出前校验操作者是房主。
- [ ] 踢出前校验目标成员存在。
- [ ] 踢出前校验目标不是房主本人。
- [ ] 调用房间模块执行目标成员离房。
- [ ] 触发 `USER_KICKED` 房间事件。
- [ ] 清理目标用户旧 `roomId` 自动重连上下文。
- [ ] 若目标在线，通过后端 WebSocket 通道下发踢出事件。
- [ ] 实现 Ban 入口。
- [ ] Ban 前校验操作者是房主。
- [ ] 写入 Ban 集合和 Ban 详情。
- [ ] 若目标当前在房间内，立即执行踢出。
- [ ] 触发 `USER_BANNED` 房间事件。
- [ ] 通知聊天模块生成 Ban 系统消息。
- [ ] 实现加入房间前 Ban 校验。
- [ ] 重复 Ban 时幂等返回成功。

## 测试验收

- [ ] 非房主无法执行禁言、踢出、Ban。
- [ ] 房主不能禁言或踢出自己。
- [ ] 禁言能阻止公共消息和定向消息。
- [ ] 禁言过期后自动恢复并清理记录。
- [ ] 踢出能移除成员关系并让用户回到大厅。
- [ ] 踢出后旧房间上下文不能自动重连恢复。
- [ ] 未 Ban 的被踢用户可以重新加入。
- [ ] Ban 后用户无法重新进入房间。
- [ ] 重复 Ban 幂等成功。

## 完成定义

- [ ] 禁言/Ban 模块任务全部完成。
- [ ] 治理命令和治理校验测试通过。
- [ ] 与房间、房间事件、聊天、用户会话模块的调用点明确。
