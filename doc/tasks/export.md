# 导出模块任务列表

> 来源：`doc/proposal.md` 14 聊天记录导出；`doc/detailed-design.md` 5.8 导出模块。

## 目标

交付后端房主导出当前保留聊天记录和房间事件日志的 JSON 能力，不新增永久存储。

## 前置约定

- 只有当前房主可以导出。
- 导出内容来自 Redis 当前保留范围。
- 导出包含系统消息和轻量事件日志。

## 最小任务

- [ ] 定义 `ChatExport` 输出结构。
- [ ] 定义 `ExportMessageItem` 输出结构。
- [ ] 定义 `ExportEventItem` 输出结构。
- [ ] 定义默认导出文件名规则 `room_{roomId}.json`。
- [ ] 实现导出入口，接收 `roomId` 和操作者 `userId`。
- [ ] 调用房主管理模块校验操作者是当前房主。
- [ ] 读取 `drrr:room:{roomId}` 房间主数据。
- [ ] 调用聊天模块读取当前仍保留的消息。
- [ ] 确保导出消息包含系统消息。
- [ ] 调用房间事件模块读取当前房间事件日志。
- [ ] 组装 `roomId`、`roomName`、`exportedAt`、`messages`、`events`。
- [ ] 输出合法 JSON 文本内容。
- [ ] 对空消息数组返回合法 JSON。
- [ ] 对空事件数组返回合法 JSON。
- [ ] 不将导出结果写入长期存储。

## 测试验收

- [ ] 非房主导出被拒绝。
- [ ] 房间不存在时导出失败。
- [ ] 导出 JSON 包含消息列表。
- [ ] 导出 JSON 包含事件列表。
- [ ] 空消息或空事件时仍能导出合法 JSON。
- [ ] 默认文件名符合 `room_{roomId}.json`。

## 完成定义

- [ ] 导出模块任务全部完成。
- [ ] 权限、结构、空数据测试通过。
- [ ] 导出 HTTP 响应结构、文件名和错误码在后端固定，供后续前端对接。
