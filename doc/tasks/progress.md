## MVP 验收映射

- [ ] 用户可输入昵称进入大厅：用户会话模块、大厅模块完成。
- [ ] 用户可创建房间：用户会话模块、房间模块、房主管理模块完成。
- [ ] 用户可加入房间：房间模块、治理模块、聊天模块完成。
- [ ] 用户可发送公共消息：聊天模块、治理模块完成。
- [ ] 用户可发送定向消息：聊天模块、治理模块完成。
- [ ] 房主可禁言：房主管理模块、治理模块、房间事件模块、聊天模块完成。
- [ ] 房主可踢人：房主管理模块、治理模块、房间模块、用户会话模块完成。
- [ ] 房主可 Ban：房主管理模块、治理模块、房间模块完成。
- [ ] 房主退出后自动继承：房间模块、房主管理模块完成。
- [ ] 断线后支持 5 分钟重连：用户会话模块、定时清理模块、房间模块完成。
- [ ] 房间无人 24 小时自动销毁：房间模块、定时清理模块完成。
- [ ] Redis 存储运行状态：所有模块 Redis Key 封装完成。
- [ ] Docker 可一键启动：后端服务与 Redis 可通过 compose 启动。
