# 后端基础设施任务列表

> 来源：`doc/detailed-design.md` 2.1 范围约束、2.3 默认设计假设、4 Redis 总体设计、8 测试设计建议。

## 目标

交付后端工程可运行骨架，为业务模块提供 HTTP、WebSocket、Redis、时间、异常处理和测试基础。

## 前置约定

- 当前阶段以后端为主，前端任务后置。
- Redis 是唯一运行态权威存储。
- HTTP 负责命令型请求，WebSocket 负责实时消息与房间内事件推送。
- 时间相关逻辑必须支持可注入时钟，便于测试 5 分钟重连窗口和 24 小时空房窗口。

- [ ] 配置后端启动入口。

- [ ] 实现健康检查接口。

## 测试验收

- [ ] 后端应用可本地启动。
- [ ] 健康检查接口返回成功。
- [ ] Redis 连接可用。
- [ ] Redis String、List、Set、ZSet 基础封装测试通过。
- [ ] WebSocket 能建立连接、断开连接并触发回调。
- [ ] 点对点推送和房间广播基础测试通过。
- [ ] 可注入时钟能在测试中推进时间。
- [ ] Docker compose 能启动后端服务和 Redis。

## 完成定义

- [ ] 后端基础设施任务全部完成。
- [ ] 后续业务模块可以复用统一响应、错误码、Redis 封装、WebSocket 通道和可注入时钟。
- [ ] 前端对接所需的 HTTP 响应和 WebSocket DTO 已在后端固定。
