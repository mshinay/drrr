# 定时清理模块任务列表

> 来源：`doc/proposal.md` 8 用户状态、9 房间生命周期；`doc/detailed-design.md` 5.9 定时清理模块。

## 目标

交付重连超时清理、空房生命周期推进、过期房间销毁和脏索引收敛能力。

## 前置约定

- 重连保留窗口为 5 分钟。
- 空房保留窗口为 24 小时。
- 房间销毁后不保留墓碑记录。

## 最小任务

- [ ] 定义 `CleanupTaskResult` 输出结构。
- [ ] 定义 `ExpiredRoomCleanupContext` 结构。
- [ ] 封装定时触发入口。
- [ ] 封装可注入时钟，便于测试 5 分钟和 24 小时窗口。
- [ ] 实现扫描 `drrr:user:reconnecting` 中超过 5 分钟的用户。
- [ ] 重连超时用户存在时，将 `UserSession.status` 置为 `OFFLINE`。
- [ ] 若重连超时用户仍在房间中，调用房间模块执行离房。
- [ ] 从 `drrr:user:reconnecting` 移除已处理用户。
- [ ] 用户主数据缺失但重连索引残留时，直接删除索引。
- [ ] 实现扫描 `drrr:room:empty` 中的空房间。
- [ ] 空房扫描时读取房间主数据。
- [ ] 空房索引存在但房间主数据缺失时，直接清理索引。
- [ ] 房间状态不是 `EMPTY` 时，以房间主数据为准清理或跳过空房索引。
- [ ] 判断 `emptySince` 是否超过 24 小时。
- [ ] 超过 24 小时时进入房间销毁流程。
- [ ] 房间销毁前触发 `ROOM_EXPIRED` 房间事件。
- [ ] 删除 `drrr:room:{roomId}`。
- [ ] 删除 `drrr:room:members:{roomId}`。
- [ ] 删除 `drrr:room:messages:{roomId}`。
- [ ] 删除 `drrr:room:events:{roomId}`。
- [ ] 删除 `drrr:room:mute:{roomId}`。
- [ ] 删除 `drrr:room:ban:{roomId}`。
- [ ] 删除房间活跃索引中的该房间。
- [ ] 删除空房索引中的该房间。
- [ ] 清理该房间相关禁言详情 Key。
- [ ] 清理该房间相关 Ban 详情 Key。
- [ ] 返回本次清理统计结果。

## 测试验收

- [ ] 重连超过 5 分钟的用户被清理为 `OFFLINE`。
- [ ] 重连超时且仍在房间中的用户会触发离房。
- [ ] 空房未满 24 小时时不会被销毁。
- [ ] 空房超过 24 小时时会完整销毁。
- [ ] 销毁后房间主数据、成员、消息、事件、治理数据均被删除。
- [ ] 销毁后同名房间可重新创建。
- [ ] 主数据缺失的脏索引能被收敛。

## 完成定义

- [ ] 定时清理模块任务全部完成。
- [ ] 时间窗口测试可通过注入时钟稳定执行。
- [ ] 与用户会话、房间、房间事件、治理模块的清理边界明确。
